🔄 キャッシュクリア手順

チャットアシスタント機能が読み込まれない場合は、以下を実行してください：

方法1：ブラウザのキャッシュをクリア（推奨）

下記キーを同時押ししてください：

  • Windows: Ctrl + Shift + Delete
  • Mac: Command + Shift + Delete

開いたウィンドウで「キャッシュされた画像とファイル」にチェックを入れて削除

方法2：ページをハード更新

下記キーを同時押ししてください：

  • Windows: Ctrl + Shift + R
  • Mac: Command + Shift + R

クリック後、数秒でメインページが開きます
